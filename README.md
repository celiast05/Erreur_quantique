# Correction d’erreurs pour les circuits quantiques

Projet de Programmation et Mathématiques – Mai 2026

## Description du projet

Ce projet a pour objectif d’introduire les principes fondamentaux du **calcul quantique** et d’étudier les mécanismes de **correction d’erreurs quantiques**, indispensables au développement d’ordinateurs quantiques fiables.

Dans un premier temps, nous présentons les bases théoriques du calcul quantique :

- le fonctionnement des **qubits** ;
- le principe de **superposition quantique** ;
- les principales **portes quantiques** (X, Z, Hadamard, CNOT) ;
- la **mesure quantique** ;
- une introduction aux avantages du calcul quantique via **l’algorithme de Deutsch**.

Nous étudions ensuite la problématique centrale de la **fragilité des états quantiques**, en introduisant :

- les erreurs de type **bit-flip (X)** ;
- les erreurs de phase **(Z)** ;
- les erreurs combinées **(Y)** ;
- le **théorème de non-clonage quantique**, empêchant la duplication directe de l’information quantique.

Enfin, nous nous intéressons aux **codes correcteurs quantiques**, notamment le **code de répétition à 3 qubits**, permettant de détecter et corriger une erreur de type bit-flip.

---

## Objectifs du projet

L’objectif principal est de :

1. Comprendre les bases du calcul quantique ;
2. Étudier la nécessité de la correction d’erreurs quantiques ;
3. Implémenter un mécanisme simple de correction d’erreur sur un **simulateur quantique Python** ;
4. Analyser le comportement du système face à un modèle de bruit élémentaire ;
5. Étudier les limites pratiques des circuits de correction.
